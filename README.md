# 쌤톡 School Starter v1.0

학생이 선생님을 골라 상담 시간을 요청하고, 선생님이 확정하거나 다른 시간을 제안하는 학교별 독립 배포용 앱입니다.

**처음 사용하는 선생님:** [SETUP.md](SETUP.md)를 열고 [CODEX-PROMPT.md](CODEX-PROMPT.md)의 문장을 자신의 Codex에 보내세요.

## 유지되는 기능

- 학생·교사 6자리 PIN, 관리자 Google 로그인, 교사 승인·삭제
- 학생 중복 등록 구분, PIN 초기화, 선택한 등록 삭제
- 일반·친구 동반·식사 상담, 시간 제안·취소·완료·기록 삭제
- 교사별 상담 가능 시간·일정, 오늘 상담, 누적 이력, 모바일 미리보기
- 학생 본인·담당 교사만 상담을 읽는 권한 구분

학교명·교표·학번 자리 수·상담 주제·요일별 시간표는 `config/school.config.json`에서 설정합니다. PIN 길이와 인증 방식은 바꾸지 않습니다. 옛 이메일 알림 기능은 포함하지 않습니다.

## 데이터는 학교마다 분리합니다

학교마다 자기 GitHub 저장소, Firebase 프로젝트, Vercel 프로젝트를 사용합니다. 다른 학교의 서비스 계정·PIN 비밀값·운영 데이터·배포 연결 폴더를 복사하면 안 됩니다. 실제 사람 이름이나 학번으로 시험하지 마세요.

관리자는 등록 목록을 관리하지만 다른 교사의 상담을 열람하는 화면은 없습니다. 학생 계정 삭제는 해당 계정과 관련 상담을 지우는 별도 관리 작업입니다. PIN은 본인 확인을 완전히 대신하지 않습니다. 학생이 학번을 알고 새 등록을 만들 수 있으므로 교사는 상담 전 학생을 확인해야 합니다.

## 로컬 미리보기

Node.js 22.12 이상(22 또는 24 버전 계열)에서 실행합니다.

```sh
npm ci
npm run dev:demo
```

미리보기는 Firebase에 연결하지 않습니다. 학생·교사 미리보기를 선택해 화면을 확인하세요. 실제 PIN 등록·로그인은 학교 설정과 서버 배포 후 확인합니다.

## 개발 검사

```sh
npm test
npm run lint
npm run build:demo
npm run test:rules
```

마지막 명령은 Java 21 이상과 첫 실행 시 인터넷 다운로드가 필요합니다. 실제 Firebase 대신 로컬 에뮬레이터만 사용합니다. `npm run build`는 학교 설정이 완료되지 않으면 실패하도록 설계되어 있습니다.

## 운영과 공유

학생 이름·학번·상담 주제·동반 친구 이름이 저장될 수 있습니다. 학교의 이용 안내, 담당자, 보관·삭제 절차를 정한 후 사용하세요. 이 앱에는 자동 보관기간 삭제 정책이 없습니다. 비용 발생 여부와 서비스 사용 조건도 학교에서 확인해야 합니다.

GitHub 공개 전 소스·자산 배포 권한과 라이선스를 확정하세요. 현재 배포 라이선스를 임의로 부여하지 않았습니다. Starter 업데이트는 각 학교 저장소에 자동으로 합쳐지지 않습니다. [CHANGELOG.md](CHANGELOG.md)를 검토한 뒤 필요한 수정만 적용하세요.
